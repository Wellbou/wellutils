# Скрипты и `--json`

Каждый отчётный тул wellutils умеет выводить то, что знает, одним JSON-документом
в stdout. Формат один и тот же во всём наборе - пишете одну логику, и она работает
независимо от того, какой тул её выдает.

Думаете, будет трудно применять? Как бы не так. Посмотрим на `whtml`. Он сам не читает ни sysfs,
ни `/proc`: просто запускает остальные тулы с `--json`, склеивает их вывод и делает
из этого одну HTML-страницу. Вот основная команда whtml:

```sh
$ whtml --output ~/report.html      # запускает wellcpu, wellhw, wellmem, ... с --json
```

## Конверт

Каждый документ начинается с одних и тех же ключей, чтобы вызывающий понимал, на
что смотрит, без угадывания:

```json
{ "tool": "wellcpu", "version": "1.4.0", "date": "2026-08-30", ... }
```

Всё остальное зависит от тула. Точная форма показана на реальных примерах с
настоящей машины в [SAMPLES.md](../SAMPLES.md).

## Быстрая демонстрация

```sh
# модель CPU, одно поле
wellhw --json | jq -r '.cpu.model'

# нагрузка по ядрам таблицей
wellcpu --json | jq -r '.load[] | "CPU\(.cpu)\t\(.usage_percent)%\t\(.freq_khz/1000) MHz"'

# самая горячая GPU без jq
wellsensors --json | python3 -c 'import json,sys;d=json.load(sys.stdin);t=[g["temp_c"] for g in (d.get("gpu") or []) if g.get("temp_c")];print(max(t) if t else "-")'

# какой сейчас апплинк?
wellnet --json | jq -r '.connection.kind'   # vpn / wifi / usb_tether / ethernet
```

Предупреждения и ошибки идут в stderr, никогда в stdout, так что поток JSON всегда
чистый - можно ставить прямо в парсер без обрезки.

## Сторожи и cron

`welldoctor` уже собирает здоровье для cron, но при желании те же проверки можно
сделать и из сырого JSON:

```sh
# команда завершится с ошибкой, когда что-то критично
welldoctor --json | jq -e '.summary.critical == 0' >/dev/null \
  || echo "welldoctor видит критичное"

# инвентарь железа для конфиг-менеджмента
wellhw --snapshot /etc/wellutils/hw.json
wellhw --diff /etc/wellutils/hw.json              # что изменилось с той недели
```

## Держим ascii-чистоту

Все тулы используют одни и те же флаги, поэтому скрипты одинаково вызываются для всего: статусбара, лога или же для простого просмотра.

```sh
wellfetch --no-emoji              # логи, которые не портят ничего в простых (tty) терминалах
```
